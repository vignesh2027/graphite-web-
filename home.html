Core Features

Built for scale. Designed for clarity.

Every tool you need to understand your infrastructure — in one beautiful interface.

Real-Time Streaming
Metrics update every 2 seconds with smooth chart animations. No page refresh, no lag — true live data streaming in the browser.
3D Network Topology
Interactive Three.js sphere showing your entire infrastructure. Orbit, zoom, hover for live CPU/memory stats on each node.
Heatmap Visualization
Canvas-drawn 24×8 latency distribution heatmap showing response time buckets across 24 hours. Instant pattern recognition.
Smart Alert Management
34 built-in alert rules. Create, silence, filter by severity. Critical/warning/info levels with firing/pending/ok states.
Visual Query Builder
Explore metrics with a hierarchical tree browser. Apply Graphite functions (movingAverage, derivative, summarize) in one click.
Export Anywhere
Export any metric query as CSV with ISO timestamps. Full data portability — take your metrics to Excel, Python, or any BI tool.
